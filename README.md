Aristocles Pty Ltd builds consumer SaaS products across career, personal finance, and AI-powered data services. The company operates from Australia, offering subscription pricing, trade cost data, PBS drug pricing, and rental market insights through a unified API platform. Their mission is to provide practical tools with clean UX, no bloat, and transparent data handling.

**Areas:** AI · Data · SaaS · Australia · Software

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Aristocles Pty Ltd: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
